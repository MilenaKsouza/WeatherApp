# 🌦️ WeatherApp

Um aplicativo de previsão do tempo desenvolvido para consultar informações meteorológicas de cidades em tempo real.

## 🚀 Sobre o projeto

O WeatherApp permite pesquisar uma cidade e visualizar suas condições climáticas, apresentando informações de forma simples e intuitiva.

## 🛠️ Tecnologias utilizadas

- Python
- Flask
- HTML5
- CSS3
- JavaScript
- OpenWeather API
- Git e GitHub

## ✨ Funcionalidades

- Pesquisa de cidades.
- Consulta da temperatura atual.
- Descrição das condições climáticas.
- Umidade do ar.
- Velocidade do vento.
- Sensação térmica.

## ⚙️ Como executar o projeto

1. Clone o repositório:

   `git clone https://github.com/MilenaKsouza/WeatherApp.git`

2. Entre na pasta:

   `cd WeatherApp`

3. Crie um ambiente virtual:

   `python -m venv .venv`

4. Ative o ambiente virtual no Windows:

   `.venv\Scripts\activate`

5. Instale as dependências:

   `pip install -r requirements.txt`

6. Crie um arquivo `.env` na raiz do projeto e adicione sua chave:

   `OPENWEATHER_API_KEY=sua_chave_aqui`

7. Execute a aplicação:

   `python app.py`

8. Acesse no navegador:

   `http://127.0.0.1:5000`

## 🔐 Segurança

A chave da API é armazenada em variável de ambiente e não deve ser publicada no GitHub.
